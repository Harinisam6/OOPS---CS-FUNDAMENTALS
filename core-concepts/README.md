# Core OOP Concepts

## Encapsulation
Bundling data and methods into a class, restricting direct access to internal state via private fields and public getters/setters.

## Inheritance
A subclass acquires properties and behavior of a parent class, enabling code reuse and hierarchy.

## Polymorphism
Same interface, different behavior. Compile-time (overloading) vs runtime (overriding).

## Abstraction
Hiding implementation details, exposing only necessary functionality through abstract classes/interfaces.

See `python_examples.py` and `java_examples.java` for working code on each.

| Concept | Java Keyword | Real-world analogy |
|---|---|---|
| Encapsulation | `private` | ATM — you use buttons, not internal wiring |
| Inheritance | `extends` | Child inherits traits from parent |
| Polymorphism | `@Override` | A "start" button means different things on different machines |
| Abstraction | `abstract`/`interface` | Driving a car without knowing engine internals |
